This will be the course website for Math 4300. Lecture notes will generally be posted shortly before the class in which they are used. Some other materials may also be posted, as needed. Most course communication will be done through Brightspace.

Course Information

Math 4300 is an introduction to the C++ programming language, and data structures and algorithms. Very roughly, the first half of the course will be spent learning how to program in C++, and the second half will be spent learning about data structures and algorithms that are broadly applicable to many programming languages.

This is intended as a second course in programming, which assumes that you have taken Math 3300 (or something similar in the past. Since Math 3300 is taught in Python, I will generally assume that students know Python. If you've programmed before but don't know Python, you can probably still take the course, since you won't be required to write any Python code. On the first day of class, a diagnostic quiz (that doesn't count toward your grade) will assess how well you know some concepts from Math 3300 that will be useful in Math 4300.
