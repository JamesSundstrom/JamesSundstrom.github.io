What exactly does the following code print? 

#include <iostream>
int main() {
    int m = 30, n = 4;
    int p = m / n;
    int r = m % n;
    double x = m / n;
    double y = static_cast<double>(m) / n;
    std::cout << p << r << x << y << std::endl;
    return 0;
}

Answer: 7277.5

First p and r are designed to be the quotient and remainder when 30 is divided by 4, which are 7 and 2. Then x is also defined to be m / n. Since m and n are ints, this division is still integer division, notwithstanding that the answer is subsequently converted to a double to store it as x, so x is also 7. When assigning y, m is cast to a double before dividing, so the division is double division, which gives 7.5. Therefore the numbers that print are 7, 2, 7, and 7.5. But the print statement doesn't insert any space between them, so the output appears as 7277.5.

What exactly does the following code print? 

#include <iostream>
int main() {
    int i = 2;
    while (i < 10) {
        if (i % 3) {
            i -= 1;
            continue;
        }
        std::cout << i << std::endl;
        i += 5;
    }
}

Answer: 

0 
3 
6

First i is initialized as 2. This is less than 10, so we enter the loop. (Every time we iterate we need to check whether i < 10, but to make it easier to focus on the interesting content, I won't mention this check for every iteration.) Then i % 3 is 2, which is converted to a bool as true since it's non-zero. Therefore we execute i -= 1 (which reassigns i to 1) and then continue, going back to the top of the loop. Again i % 3 is nonzero, so we subtract 1 from i and continue. Then i is 0, so i % 3 is treated as false, which causes us to print i (0) and then add 5 to i. The same process repeats, with i becoming 4, 3, 8, 7, 6, 11 (and printing every time it's divisible by 3). Finally, once i is 11, we break out of the loop.

What exactly does the following code print? 

#include <iostream>
int f(int i, int j) {
    if (j <= 0) {
        return (i % 3 == 0) ? i : f(i / 3, 2);
    }
    return f(i+1, j-1);
}

int main() {
    std::cout << f(9, 400) << std::endl;
    return 0;
}

Answer: 138

When f(i, j) is called with a positive j, it returns f(i+1, j-1). If j-1 > 0, then f(i+1, j-1) returns f(i+2, j-2). This pattern continues until the second argument is 0, i.e., until f(i+j, 0). This proves that for any positive number j, f(i, j) eventually returns f(i+j, 0).

Therefore f(9, 400) returns f(409, 0). Note that 409 divided by 3 is 136 with a remainder of 1, so (i % 3 == 0) ? i : f(i / 3, 2); evaluates to f(136, 2). As we saw before, this evaluates to f(138, 0). Since 138 is divisible by 3, this returns 138.

We say that a set of integers is shy if it does not contain any two consecutive integers. For example, {1, 3, 6} is shy and {1, 3, 4, 6} is not. Define a function shySets(n) that takes as argument a non-negative int n, and returns a std::vector<std::vector<int>> consisting of all the shy subsets of {0, 1, ..., n-1}. For example, shySets(0) should return {{}} and shySets(3) should return {{}, {0}, {1}, {2}, {0, 2}} (in any order).

You do not need to worry about making your code run efficiently for this problem. (It's a good exercise to think about that, but on a test you just need to write code that works in theory, unless the problem specifically asks for efficiency.)

Answer: The simplest way to solve this problem is using recursion. We find all the shy subsets of {0, ..., n-1} by considering separately the subsets which do/do not contain n-1. Any subset which does not contain n-1 is a shy subset of {0, ..., n-2}, so we get those from shySets(n-1). Any subset which does contain n-1 cannot contain n-2, so the remaining elements form a shy subset of {0, ..., n-3}. We get those from shySets(n-2) (pushing n-1 into each one to get the set we actually want).

Warning: This function is not very fast; you probably don't want to ask for shySets(n) for n much larger than 30. 

#include <vector>

std::vector<std::vector<int>> shySets(int n) {
    if (n == 0) {return {{}};}
    if (n == 1) {return {{}, {0}};}
    auto answer = shySets(n - 1);
    auto others = shySets(n - 2);
    for (auto& other : others) {
        other.push_back(n - 1);
        answer.push_back(other);
    }
    return answer;
}

Note the use of auto to avoid repeatedly typing the tedious std::vector<std::vector<int>>.

Consider the following code:

#include <iostream>

int main() {
    int n;
    std::cout << "Enter an integer: ";
    std::cin >> n;
    int* arr = n < 0 ? nullptr : new int[n];
    for (int i = 0; i < n; ++i) 
        arr[i] = i*i;
    for (int* p = arr; p && *p < 40; p += 2)
        std::cout << *p << std::endl;
    delete[] arr;
    return 0;
}

(a) If the user enters 10, what does this program print?

Answer: 

0
4
16
36

The code fills the array arr with perfect squares from 02 to to (n-1)2, The loop initializes p = arr to point to arr[0], and then after each iteration it points to arr[2], arr[4], etc. In other words, the pointer successively points to each even square. The loop stops when *p < 40 is false; the first even square for which this is false is 64, so the loop prints 0, 4, 16, and 36.

(b) Are there any integers that the user could enter which would cause this program to have undefined behavior? If not, explain why not. If so, explain which inputs cause undefined behavior.

Answer: The behavior of the program is undefined if the user enters any integer from 0 to 8 (inclusive).

Remember that the loop continues until p points to a number greater than 40. As discussed above, p points to even squares in arr, so the loop will terminate before p points outside of arr as long as arr contains an even square greater than or equal to 40. This is the case if n > 9. If 0 <= n <= 8, then arr does not contain an even square that stops the iteration, so p continues beyond the bounds of the array, leading to undefined behavior.

Note that entering a negative number does not result in undefined behavior. In that case, p is initialized as a null pointer, so p && *p < 40 evaluates to false before the first iteration of the loop, so the program never attempts to dereference a null pointer. (Note also that evaluating p && *p < 40 doesn't involve dereferencing a null pointer due to short-circuit evaluation). Finally, delete[] arr is not a problem in this case either, because deleting a null pointer is defined as doing nothing.

Consider the following code:

#include &;lt;iostream>
#include <vector>
#include <algorithm>

int f(std::vector<int> v, int n = -1) {
    if (n < 0 || n > v.size()) 
        n = v.size();
    if (n == 0) return 0;
    return f(v, n-1) + std::count_if(v.begin(), v.begin() + n, [](int a) {return a % 2 == 0;});
}

int main() {
    std::vector<int> v{42, 5, 1729, -6, 3, 18};
    std::cout << f(v) << std::endl;
    return 0;
}

(a) What does the code print?

Answer: 10

Let c(v, n) denote the number of even entries among the first n entries of v. Then f(v, n) returns f(v, n-1) + c(v, n). Continuing recursively, this is f(v, n-2) + c(v, n-1) + c(v, n), and so on until c(v, 1) + ... + c(v, n). In the above example, this is 1 + 1 + 1 + 2 + 2 + 3, which is 10.

Alternatively, note that in the formula c(v, 1) + ... + c(v, n), if v[i] is even, then it is counted by c(v, i+1) through c(v, n), i.e., it is counted n-i times. Therefore f(v, n) can also be expressed as the sum of n-i for those values of i for which v[i] is even. In the above example, v[i] is even when i is 0, 3, or 5, so f(v) equals (6 - 0) + (6 - 3) + (6 - 5) = 6 + 3 + 1 = 10.

(b) Can you rewrite the code for f to do the same thing without using recursion? (At least not explicitly -- if you want, you can call standard library algorithms without worrying about how they're implemented.)

Answer: Three solutions are provided below. The first is based on the formula c(v, 1) + ... + c(v, n) described in the answer to part (a). The other two are based on the "sum of n-i" formula described in the alternative solution to part (a); one uses a straightforward loop, while the other uses std::accumulate. 

#include <vector>
#include <algorithm>

int f(const std::vector<int>& v, int n = -1) {
    if (n < 0 || n > v.size()) 
        n = v.size();
    int total{0};
    for (int i = 1; i <= n; ++i) {
        total += std::count_if(v.begin(), v.begin() + i, [](int a) {return a % 2 == 0;});
    }
    return total;
}
 

#include <vector>
#include <algorithm>

int f(const std::vector<int>& v, int n = -1) {
    if (n < 0 || n > v.size()) 
        n = v.size();
    int total{0};
    for (int i = 0; i < n; ++i) {
        if (v[i] % 2 == 0) {
            total += n - i;
        }
    }
    return total;
}
 

#include <vector>
#include <numeric>

int f(const std::vector<int>& v, int n = -1) {
    if (n < 0 || n > v.size()) 
        n = v.size();
    int i = 0;
    return std::accumulate(v.begin(), v.begin() + n, 0, [&i, n](int acc, int val) 
        {int result = acc + (val % 2 == 0 ? (n - i) : 0); ++i; return result;});
}

Define a function sortByDistance which accepts two arguments, a std::vector<double> v and a double target, and sorts the elements of v by their distance from target. Sort from closest to furthest. For example, if v is {2.0, -1.1, 5.4, 1.9} and target is 3.2, then after calling f(v, target), v should be {2.0, 1.9, 5.4, -1.1}.

Hint: You can access the absolute value function std::abs from the cmath header.

Answer:

#include <vector>
#include <cmath>
#include <algorithm>

void sortByDistance(std::vector<double>& v, double target) {
    auto f = [target](double x, double y) {return std::abs(x - target) < std::abs(y - target);};
    std::sort(v.begin(), v.end(), f);
}

Define a function longestSubstringWithoutPeriods which accepts as argument a std::string s and returns the longest substring of s that does not contain any periods. (In the event of a tie, you may choose any of the options.)

For example, if s is "www.google.com", the function should return "google"; if s is "abcdefg", the function should return "abcdefg".

Answer: Perhaps the easiest way to solve the problem is with recursion. Find the first period-free substring, then recursively find the longest period-free substring from the rest of s, and compare the two options to see which is longest. Two solutions are provided below using this algorithm, one via the find method of the string class, and the other via std::find: 

#include <string>

std::string longestSubstringWithoutPeriods(const std::string& s) {
    int size = s.find("."); // Size of first substring
    if (size == std::string::npos) return s;
    std::string other = longestSubstringWithoutPeriods(s.substr(size + 1));
    return size >= other.size() ? s.substr(0, size) : other;
}
 

#include <string>
#include <algorithm>

std::string longestSubstringWithoutPeriods(const std::string& s) {
    auto it = std::find(s.begin(), s.end(), '.');
    if (it == s.end()) return s;
    int size = it - s.begin(); // Size of first substring
    std::string other = longestSubstringWithoutPeriods(s.substr(size + 1));
    return size >= other.size() ? s.substr(0, size) : other;
}

Given numbers r0, ..., rn-1, the corresponding square Vandermonde matrix is the n x n matrix for which row i of the matrix consists of ri0, ri1, ..., rin-1. Define a function double** vandermonde(const double* numbers, int n) that accepts as arguments an array of doubles and a positive integer n representing the number of doubles in the array, and returns the corresponding n x n Vandermonde matrix (as a two-dimensional C-style array).

Answer:

double** vandermonde(const double* numbers, int n) {
    double** matrix = new double*[n];
    for (int i = 0; i < n; ++i) {
        matrix[i] = new double[n];
        matrix[i][0] = 1.0;
        for (int j = 1; j < n; ++j) {
            matrix[i][j] = numbers[i] * matrix[i][j-1];
        }
    }
    return matrix;
}
