We say that a set of integers is shy if it does not contain any two consecutive integers. For example, {1, 3, 6} is shy and {1, 3, 4, 6} is not. For example, shySets(0) should return {{}} and shySets(3) should return {{}, {0}, {1}, {2}, {0, 2}} (in any order).

You do not need to worry about making your code run efficiently for this problem. (It's a good exercise to think about that, but on a test you just need to write code that works in theory, unless the problem specifically asks for efficiency.)

The below code is supposed to calculate the average of numbers entered by the user, but it has three bugs. Identify the bugs and explain how to correct them (with as few changes as possible). 

#include <iostream>

double average(int arr[]) {
    int size = arr.size();
    int total = 0;
    for (int i = 0; i < size; ++i) {
        total += arr[i];
    }
    return total / size;
}

int main() {
    int n;
    std::cout << "Enter a positive integer: ";
    std::cin >> n;
    int arr[n];
    std::cout << "Enter n integers: ";
    for (int i = 0; i < n; ++i) {
        std::cin >> arr[i];

    return 0;
}
