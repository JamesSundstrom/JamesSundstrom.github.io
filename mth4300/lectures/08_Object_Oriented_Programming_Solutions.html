Linked List Exercise (Back to lecture)

A linked list is a data structure in which data is stored sequentially in nodes. Each ListNode contains two attributes: the value that it stores (which we'll assume is an int for this exercise), and a pointer to the next ListNode in the list. (The last ListNode has a null pointer to indicate that it's the end.) Then the only data stored directly in the LinkedList class itself is a pointer to the first node, because that's all you need: the first node points to the second, which points to the third, and so on, so we have enough information to access the entire list. We saw before that our employee/supervisor example was essentially forming a linked list of employees.

For this exercise, you'll create a simple linked list class. It should include:

  • A struct ListNode which stores an int and a pointer to the next ListNode.
  • A constructor that takes no argument, and constructs a new empty linked list.
  • A constructor that takes as argument an int, and constructs a new linked list consisting of a single node storing that int as its data.
  • A method insertAtHead that takes as argument an int, and adds a node storing that int at the beginning of the list.
  • A method pop that takes no arguments, deletes the first node in the list, and returns the int that was stored there. (Your program should crash if this is run on an empty list -- it's the caller's responsibility to check that the list is nonempty.)
  • A method isEmpty that takes no arguments, and returns a bool indicating whether the list is empty.

Here's some code you can use to test your class. It should print the numbers 2 3 5 7 11 in that order. 

#include <iostream>

    // Define the LinkedList class here

    int main() {
        LinkedList list(11);
        list.insertAtHead(7);
        list.insertAtHead(2);
        std::cout << list.pop() << std::endl;
        list.insertAtHead(5);
        list.insertAtHead(3);
        while (!list.isEmpty()) {
            std::cout << list.pop() << std::endl;
        }
        return 0;
    }

Note that you've implemented a stack -- a last-in-first-out (LIFO) data structure. Since you insert data at the head of the list, the most-recently-inserted data is always the first data that gets read.

If you get all that working and still have time, make sure you have no memory leaks! The pop method should free memory for the node it deletes, and your class should have a destructor that frees memory for all the nodes!

Answer: A solution is provided below. Note that we can define the ListNode structure as private within the LinkedList class. This supports proper encapsulation: code outside of the LinkedList class doesn't have access to the details of how we implemented the linked list. 

class LinkedList {
public:
    LinkedList() : head_(nullptr) {}
    LinkedList(int val) : head_(new ListNode{val, nullptr}) {}
    ~LinkedList() {
        while (head_) {
            ListNode* next = head_->next;
            delete head_;
            head_ = next;
        }
    }
    void insertAtHead(int val) {head_ = new ListNode{val, head_};}
    int pop() {
        int val = head_->val;
        ListNode* oldHead = head_;
        head_ = head_->next;
        delete oldHead;
        return val;
    }
    bool isEmpty() const {return head_ == nullptr;}
private:
    struct ListNode {
        int val;
        ListNode* next;
    };
    ListNode* head_;
};
