  1. What does the below code print? Try to figure it out without running the code. 
    #include <iostream>

int triple(int n) {
    n *= 3;
    return n;
}

int quadruple(int& n) {
    n *= 4;
    return n;
}

int main() {
    int a{5}, b{6}, c, d;
    c = triple(a);
    d = quadruple(b);
    std::cout << a << " " << b << " " << c << " " << d << std::endl; 
    return 0;
}

    Answer: 5 24 15 24

    The function triple has no effect on its argument, since the argument is passed by value. Hence after c = triple(a), a is still 5 and c is 15. On the other hand, quadruple does change its argument, so after d = quadruple(b), b and d are both 24.

  2. Define a function withoutVowels(word) that accepts as argument a string word and returns the string consisting of word with its vowels (A, E, I, O, U) removed. Your function should not unnecessarily copy word, nor should it be able to modify the contents of word.

    Answer:

    #include <string>

bool isVowel(char c) {
    if ('A' <= c && c <= 'Z') c = c - 'A' + 'a';
    switch (c) {
        case 'a':
        case 'e':
        case 'i':
        case 'o':
        case 'u':
            return true;
        default:
            return false;
    }
}

std::string withoutVowels(const std::string& word) {
    std::string s{""};
    for (char c : word) {
        if (!isVowel(c)) s += c;
    }
    return s;
}

  3. Using your previous answer, define a void function removeVowels(words) which accepts as argument a std::vector<std::string> called words and removes all the vowels from the words in the vector.

    Answer:

    #include <string>
#include <vector>

void removeVowels(std::vector& words) {
    for (int i = 0; i < words.size(); ++i)
        words[i] = withoutVowels(words[i]);
}

Recursion Exercise (Back to lecture)

Consider the sequence an of real numbers defined by a0 = 1 and an+1 = 1 + 1/an. Define a function a(n) that calculates this sequence. Use it to estimate the limit of an as n goes to infinity.

If you finish before your classmates, write a different version of an, so that you have one version of the code using recursion and one using a loop. Which one do you prefer?

Answers: The recursive and non-recursive solutions are shown below. 

double a(int n) {
    return n <= 0 ? 1.0 : 1.0 + 1.0 / a(n - 1);
}
 

double a(int n) {
    double val{1.0};
    for (int i = 0; i < n; ++i)
        val = 1.0 + 1.0 / val;
    return val;
}

If you evaluate a(n) for a large value of n (say, at least 12), you'll get a value approximately 1.61803, so you can conclude that the limit of an is approximately 1.61803. In fact, the exact value of the limit is (1 + sqrt(5)) / 2 = 1.61803..., which is the famous Golden Ratio.
