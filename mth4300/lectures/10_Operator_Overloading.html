Lecture 10: Operator Overloading

So far, we've added a bunch of technical memory-management methods to our Polynomial class, but we haven't added most of the operations that we would like to be able to do with polynomials, such as addition, subtraction, and multiplication. There's a reason for that.

Suppose you have three Polynomials, f, g, and h, and you want to calculate f * g + h. If you were going to do that with material that we've covered so far, you might define methods Polynomial::add and Polynomial::multipliy and then write something like f.multiply(g).add(h). But that's annoying to type and hard to read: we would like to be able to write f * g + h in our code. That's where operator overloading comes in.

Recall that overloading refers to the idea that we can have multiple functions with the same name, distinguished by the types of their arguments. Well, addition is a function, so we can overload it too. (We sometimes don't think of it as a function because we write things like "a+b" instead of "+(a, b)," but it is a function: it accepts two arguments and returns a result.) In particular, if we define a version of the addition operator that accepts two Polynomial objects as arguments, then we'll be able to use + to add Polynomial objects.

We've already seen an example of operator overloading: the copy assignment operator and move assignment operators both overload the operator =. Recall that the way we accomplished that was by defining a function operator= as a member function within our class. We'll overload other operators in basically the same way: name the function operator plug the symbol that you're trying to overload.

We'll continue using Polynomial for the examples in this lecture. For your convenience, the code is provided below (and consolidated into one file) for you to copy: 

// polynomial.h: 
#pragma once

#include <vector>

class Polynomial {
public:
    Polynomial(const std::vector<int>& coefficients);
    Polynomial(const Polynomial& other);
    Polynomial(Polynomial&& other) noexcept;
    Polynomial& operator=(const Polynomial& other);
    Polynomial& operator=(Polynomial&& other) noexcept;
    ~Polynomial();
    int eval(int n) const;
private:
    int degree_;
    int* coefficients_;
};

// polynomial.cpp:

#include <vector>
#include <numeric>
//#include "polynomial.h" // Not used in the in-class version which puts everything in one file

// Copy the given coefficients vector into coefficients_, while also removing 
// any leading zeros so that degree_ is calculated correctly.
Polynomial::Polynomial(const std::vector<int>& coefficients) {
    int i;
    for (i=0; i < coefficients.size(); ++i) {
        if (coefficients[i] != 0) {
            break;
        }
    }
    degree_ = coefficients.size() - i - 1;
    coefficients_ = new int[degree_ + 1];
    for (int j = i; j < coefficients.size(); ++j) {
        coefficients_[j-i] = coefficients[j];
    }
}

// Copy constructor
Polynomial::Polynomial(const Polynomial& other)
    : degree_(other.degree_), coefficients_(new int[degree_ + 1]) {
    std::copy(&other.coefficients_, &other.coefficients_ + degree_ + 1, &coefficients_);
}

// Move constructor
Polynomial::Polynomial(Polynomial&& other) noexcept
    : degree_(other.degree_), coefficients_(other.coefficients_) {
    other.degree_ = -1; 
    other.coefficients_ = nullptr;
}

// Copy assignment operator
Polynomial& Polynomial::operator=(const Polynomial& other) {
    if (this == &other) {return *this;}
    delete[] coefficients_;
    degree_ = other.degree_;
    coefficients_ = new int[degree_ + 1];
    std::copy(&other.coefficients_, &other.coefficients_ + degree_ + 1, &coefficients_);
    return *this;
}

// Move assignment operator
Polynomial& Polynomial::operator=(Polynomial&& other) noexcept {
    if (this == &other) return *this;
    delete[] coefficients_;
    degree_ = other.degree_;
    coefficients_ = other.coefficients_;
    other.degree_ = -1;
    other.coefficients_ = nullptr;
    return *this;
}

Polynomial::~Polynomial() {
    delete[] coefficients_;
}

int Polynomial::eval(int n) const {
    auto f = [n](int acc, int val) { return acc * n + val; };
    return std::accumulate(coefficients_, coefficients_ + degree_ + 1, 0, f);
}

How to overload operators

Before we start overloading some more operators, there's one more technicality that we need to discuss: where do we define our overloaded operators?

For example, we've seen that when you overload the assignment operator, you define the function as a member function of your class, e.g., Polynomial::operator=. Specifically, when you overload an operator, the overloaded operator is defined as a member function of the left argument, e.g., when we were overloading f = g by defining Polynomial::operator=(Polynomial&& other), f was the object pointed to by this, and g was other.

But for some operators, this wouldn't make sense. Suppose you tried to overload the << operator, so that you could write code like std::cout << f and print your polynomial to standard output. Since std::cout is the left argument, if we tried to define operator<< as a member function of a class, it would need to be a member of std::cout's class (which is std::ostream). Of course, you can't modify the code for std::ostream, so this is impossible.

Unfortunately, things now get a little complicated: some overloaded operators must be member functions, some must be non-member functions, and some can be defined either way (though there are style guidelines that you should prefer one or the other). Specifically:

  • Must be a member function: = (assignment), [] (subscript), () (function call), -> (member access).
  • Should be a member function: Operators that are bound tightly to a single object, such as unary operators such as ! and ++ and compound assignment operators such as +=. (Note that you must overload += separately even if you already overloaded +. In fact, it's recommended that you overload += first and then use it to define +.)
  • Should be a non-member function: Symmetric binary operators, such as +, -, *, ==, !=.
  • Must be a non-member function: Stream I/O operations (<< and >>).

friend

The discussion in the previous section raises a new problem. For example, we said that we wanted to overload the + operator using a non-member function. But how are we going to do that? For example, calculating the sum of two polynomials requires us to know their coefficients, but the coefficients_ array is private, so a non-member function can't access it. (In theory, we could solve this by making the implementation details public, but we don't necessarily want to do that.)

The answer is that we can declare a non-member function as a friend of our class: a friend function has access to the private attributes of the class, as if it were a member function. Basically, you declare the function in the public section of the class as if it were a member function, but with the keyword friend at the beginning. We'll see an example soon, but first lets add one new feature to our Polynomial class.

coefficient

Let's define a method coefficient that returns the coefficient of x^n in our Polynomial.

Aside: I considered implementing this as an overload of operator[], so that f[n] represents the coefficient of x^n in f. This saves us a little typing over needing to write out f.coefficient(n), but on the other hand, f[n] looks a lot like f(n), so it might cause more confusion than it's worth. Perhaps it's better to do accept a little more typing in return for readable code.

Add the following (public) declaration to the Polynomial class: 

int coefficient(int i) const;

and the following definition: 

int Polynomial::coefficient(int i) const {
    return (i < 0 || i > degree_) ? 0 : coefficients_[i];
}

Besides providing a public method so that users of our Polynomial class can check the coefficients of a Polynomial, this will be a convenience for us even while we're working within the class. We now have a bounds-checked coefficient function, so that we don't need to add manual bounds-checking when accessing coefficients. Now we'll use it to define addition.

Overloading the addition operators

Now we're ready to define addition of polynomials. As mentioned above, it's good form to start by overloading the += operator. We'll need the std::max function in order to do that, so add #include <algorithm> at the top of your polynomial.cpp.

Now add the following public declaration in polynomial.h: 

Polynomial& operator+=(const Polynomial& other);

And add the following definition in polynomial.cpp: 

Polynomial& Polynomial::operator+=(const Polynomial& other) {
    int newDegree = std::max(this->degree_, other.degree_);
    while (newDegree > -1 && this->coefficient(newDegree) + other.coefficient(newDegree) == 0) {
        --newDegree;
    }
    int* newCoefficients = new int[newDegree + 1];
    for (int i = 0; i <= newDegree; ++i) {
        newCoefficients[i] = this->coefficient(i) + other.coefficient(i);
    }
    delete[] coefficients_;
    coefficients_ = newCoefficients;
    degree_ = newDegree;
    return *this;
}

The declaration should be largely as you expect. As mentioned above, we overload += as a member function. Of course, we pass other as a constant reference, because we don't want to make an unnecessary copy of other, but we also don't want to modify it. Notice that we return this*; as we saw with the assignment operator, this supports operator chaining.

We haven't mentioned this before, but the += operator can be chained: you can write a += b += c to mean "First add c to b, and then add the new value of b to a." You should never do this: it's much clearer to simply write b := c; a := b; as two separate lines. But your overloaded += should support it correctly even though it's generally bad style.

Now, define operator+. First, add this as a public declaration in polynomial.h: 

friend Polynomial operator+(Polynomial f, const Polynomial g);

And add the definition to polynomial.cpp: 

Polynomial operator+(Polynomial f, const Polynomial& g) {
    f += g; 
    return f;
}
