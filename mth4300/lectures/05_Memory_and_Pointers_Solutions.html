Exercise on const (Back to lecture)

Without running the following code, try to predict which lines of code are not allowed. If we delete the illegal lines of code, what does the program print? 

#include <iostream>

int main() {
    int x{1}, y{2}, z{3};
    const int* p = &x;
    int* const q = &y;
    const int* const r = &z;
    p = &y;
    *p = 5;
    q = &z;
    *q = 7;
    r = &x;
    *r = 6;
    std::cout << x << ' ' << y << ' ' << z << ' ' << *p << ' ' << *q << ' ' << *r << std::endl;
    return 0;
}

Answer: The invalid lines are commented out below: 

#include <iostream>

int main() {
    int x{1}, y{2}, z{3};
    const int* p = &x;
    int* const q = &y;
    const int* const r = &z;
    p = &y;
    // *p = 5; // p is a pointer to a const int, so it can't be used to modify the value it points to
    // q = &z; // q is a constant, so it can't be changed
    *q = 7;
    // r = &x; // r is a constant, so it can't be changed
    // *r = 6; // r is a pointer to a const int, so it can't be used to modify the value it points to
    std::cout << x << ' ' << y << ' ' << z << ' ' << *p << ' ' << *q << ' ' << *r << std::endl;
    return 0;
}

When this code is run, it prints 1 7 3 7 7 3.

Explanation: At the end, x and z are unchanged from their original values, while y has been changed to 7 by *q = 7. Also, q and r still contain their original addresses, while p points to y.

The Office Exercise (Back to lecture)

Using our Employee structure from earlier, write a function topLevelSupervisor which accepts an Employee as argument and returns the Employee's "top-level supervisor" (i.e., the supervisor's supervisor's supervisor's ... until we reach the top of the corporate ladder). Note that an Employee who does not have an assigned supervisor is considered their own top-level supervisor.

Since we haven't covered structures yet, the only thing you need to know about them is that, if e is an Employee, then e.supervisor returns (a pointer to) e's supervisor.

If your functioin works correctly, then the sample code below should identify David Wallace as the top-level supervisor of each Employee in the example. 

#include <iostream>

struct Employee {
    std::string name;
    Employee* supervisor;
};

Employee topLevelSupervisor(const Employee& e) {
    // Write your code here
} 

void printTopLevelSupervisor(const Employee& e) {
    std::cout << e.name << "'s top-level supervisor is " <<
                 topLevelSupervisor(e).name << std::endl;
}

int main() {
    Employee DavidWallace{"David Wallace", nullptr};
    Employee MichaelScott{"Michael Scott", &DavidWallace};
    Employee DwightSchrute{"Dwight Schrute", &MichaelScott};

    printTopLevelSupervisor(DavidWallace);  
    printTopLevelSupervisor(MichaelScott); 
    printTopLevelSupervisor(DwightSchrute);
    return 0;
}

Answer: 

Employee topLevelSupervisor(const Employee& e) {
    const Employee* ptr = &e;
    while (ptr->supervisor) 
        ptr = ptr->supervisor;
    return *ptr;
}
