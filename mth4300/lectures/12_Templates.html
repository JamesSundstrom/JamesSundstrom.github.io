Lecture 12: Templates

Motivation

Often, we write boilerplate code that is applicable to many different data types. For example, the max function which returns the maximum of two values is relevant to any type that has a comparator, and the exact same code works for every such type:

return (x > y) ? x : y;

It would be nice to be able to write this code once and have it work for any type, rather than needing to write a separate max function for every type.

Similarly, there are classes that are designed to interact with other classes. For example, std::vector can create a vector of ints, or of std::strings, or even of a class that you created yourself.

Templates allow us to create a class or function that works polymorphically with many different types, without needing to rewrite the code for each type we want to work with. Instead, we provide a placeholder (usually denoted T) for the type, and the compiler generates code that replaces T with whatever types the class/function is used with.

Function Templates

A function template can be parametrized by one or more types. Before declaring the function, you use the template keyword followed by the type parameter list. The parameter list is written between angle brackets. (This is easy to remember -- the brackets for declaring the type parameters are the same as you're used to when declaring a parametrized type, e.g., std::vector<int>.) Usually the parameters will be types, so you declare them using the typename keyword. (You can use class instead of typename, but typename is considered better style.) For example, below is our example for calculating the maximum. (It would be better style to name it max, since that's how programmers usually refer to the maximum function, but in this case what would have collided with a built-in max function.) 

#include <iostream>
#include <string>

template <typename T>
T maximum(T x, T y) {
    return (x > y) ? x : y;
}

int main() {
    std::string dog{"dog"}, cat{"cat"};
    std::cout << maximum(3, 4) << std::endl;         // 4
    std::cout << maximum(3.14, 2.72) << std::endl;   // 3.14
    std::cout << maximum(cat, dog) << std::endl;     // dog
    return 0;
}

Aside: Why was it important that we declared std::string variables rather than calling maximum("cat", "dog") directly?

Of course, you wouldn't generally write the above code yourself, because you can get the std::max function from the <algorithm> header.

As we saw above, we were able to simply write maximum, not maximum<int>; the compiler is able to deduce the relevant type by looking at the arguments to the function. If the two arguments to maximum were different types, then the code would not compile, because the compiler could not determine what T represents: 

#include <iostream>

template <typename T>
T maximum(T x, T y) {
    return (x > y) ? x : y;
}

int main() {
    std::cout << maximum(3, 5.5) << std::endl; // Does not compile!
    return 0;
}

This example might seem silly to you. We should be able to determine the maximum of 3 and 5.5, because C++ normally lets us compare an int to a double, by casting the int to a double. However, template type deduction does not perform implicit conversions for us. If we want to find the maximum of 3 and 5.5, we have two options. We could cast the int to a double before passing it into the function, so that the function receives two doubles and everything works as usual. Alternatively, we could explicitly tell the compiler what T to use, by providing it inside angle brackets (exactly as we do for parametrized types like std::vector<int>). Now the compiler knows that maximum<double> is supposed to take doubles as arguments, so when it receives an int instead it can perform implicit type conversion as usual: 

#include <iostream>

template <typename T>
T maximum(T x, T y) {
    return (x > y) ? x : y;
}

int main() {
    std::cout << maximum<double>(3, 5.5) << std::endl; // 5.5
    return 0;
}

share Exercise (Solution)

Define a function template share(x, y) which accepts references to x and y and modifies the values stored there so that both are equal to (x + y) / 2, i.e., they now share equally. (If x and y were integral types and x+y was odd, then in the course of sharing whatever it is that we're sharing, we've actually lost one. That's okay -- that's just the cost of sharing fairly.)

If your function works correctly, the below test code should print 4 4 9 9 2.9 2.9:

int main() {
    int a{2}, b{7}, c{13}, d{5};
    double x{3.1}, y{2.7};
    share(a, b);
    share(c, d);

Class templates

You can parametrize a class using the exact same syntax as we used to parametrize a function. The biggest difference is that, when a parametrized class is used, the parameter must always be provided inside angle brackets. (For a function, the parameter can usually be inferred by the compiler from the parameters, but that may not be the case for a class.)

For example, we've been working on the example of a Polynomial class. So far, our polynomial has always had int coefficients, but that's not how polynomials work in math. Why can't we have a polynomial with real coefficients, or complex coefficients, or even more exotic coefficients?

We could turn our Polynomial class into a template which is parametrized by the type of the coefficients. Before we do that, there's one technical detail we need to be aware of:

Templates and .h files

One somewhat unfortunate downside of using templates is that we can no longer separate declaration and implementation into .h and .cpp files. Since the template is merely a blueprint from which the compiler will generate code for each needed T, the compiler needs to have access to the full implementation; we cannot simply provide it with the declaration in a .h file and link the .cpp file later.

This means that we have to put the entire class definition inside the .h file, so that the compiler has access to it when compiling anything that includes the .h file.

polynomial.h

Here's our new polynomial.h, with all the definitions now moved here:

#pragma once

#include <vector>
#include <ostream>
#include <algorithm>
#include <numeric>

template <typename T>
class Polynomial {
public:
    Polynomial(const std::vector<T>& coefficients);
    Polynomial(T c);
    Polynomial(const Polynomial& other);
    Polynomial(Polynomial&& other) noexcept;
    ~Polynomial();
    Polynomial& operator=(const Polynomial& other);
    Polynomial& operator=(Polynomial&& other) noexcept;
    T& operator[](size_t i);
    const T& operator[](size_t i) const;
    Polynomial& operator+=(const Polynomial& other);
    friend Polynomial operator+(Polynomial f, const Polynomial& g) {
        f += g; 
        return f;
    }
    Polynomial& operator-=(const Polynomial& other);
    friend Polynomial operator-(Polynomial f, const Polynomial& g) {
        f -= g; 
        return f;
    }
    Polynomial& operator*=(const Polynomial& other);
    friend Polynomial operator*(Polynomial f, const Polynomial& g) {
        f *= g; 
        return f;
    }
    friend bool operator==(const Polynomial& f, const Polynomial& g) {
        if (f.degree_ != g.degree_) {return false;}
        for (int i = 0; i <= f.degree_; ++i) {
            if (f.coefficients_[i] != g.coefficients_[i]) {return false;}
        }
        return true;
    }
    friend std::ostream& operator<<(std::ostream& os, const Polynomial& f) {
        if (f.degree_ == -1) { // Print the 0 polynomial correctly
            os << '0';  
            return os;
        }
        for (int d = f.degree_; d >= 0; --d) {
            T coeff = f.coefficient(d);
            if (coeff == T(0)) {continue;}
            // Print coefficient
            if (d == f.degree_) {
                if (coeff == T(1)) {
                    if (d == 0) {os << '1';} 
                } else if (coeff == -1) {
                    os << (d == 0 ? "-1" : "-");
                } else {
                    os << coeff;
                }
            } else {
                os << (coeff > 0 ? " + " : " - ");
                if ((coeff != 1 && coeff != -1) || d == 0) {os << std::abs(coeff);} 
            }
            // Print power of x
            if (d == 1) {
                os << 'x';
            } else if (d > 1) {
                os << "x^" << d;
            }
        }
        return os;
    }
    T operator()(T n) const;
    T eval(T n) const;
    T coefficient(int i) const;
private:
    int degree_;
    T* coefficients_;
};

// Copy the given coefficients vector into coefficients_, while also removing 
// any leading zeros so that degree_ is calculated correctly.
template <typename T>
Polynomial<T>::Polynomial(const std::vector<T>& coefficients) {
    int i;
    for (i=0; i < coefficients.size(); ++i) {
        if (coefficients[i] != 0) {
            break;
        }
    }
    degree_ = coefficients.size() - i - 1;
    coefficients_ = new T[degree_ + 1];
    for (int j = i; j < coefficients.size(); ++j) {
        coefficients_[j-i] = coefficients[j];
    }
}

// Construct a constant polynomial
template <typename T>
Polynomial<T>::Polynomial(T c) : Polynomial(std::vector<T>{c}) {}

// Copy constructor
template <typename T>
Polynomial<T>::Polynomial(const Polynomial& other)
    : degree_(other.degree_), coefficients_(new T[degree_ + 1]) {
    std::copy(other.coefficients_, other.coefficients_ + degree_ + 1, coefficients_);
}

// Move constructor
template <typename T> 
Polynomial<T>::Polynomial(Polynomial&& other) noexcept
    : degree_(other.degree_), coefficients_(other.coefficients_) {
    other.degree_ = -1; 
    other.coefficients_ = nullptr;
}

template <typename T> 
Polynomial<T>::~Polynomial() {
    delete[] coefficients_;
}

// Copy assignment operator
template <typename T> 
Polynomial<T>& Polynomial<T>::operator=(const Polynomial& other) {
    if (this == &other) {return *this;}
    delete[] coefficients_;
    degree_ = other.degree_;
    coefficients_ = new T[degree_ + 1];
    std::copy(other.coefficients_, other.coefficients_ + degree_ + 1, coefficients_);
    return *this;
}

// Move assignment operator
template <typename T> 
Polynomial<T>& Polynomial<T>::operator=(Polynomial<T>&& other) noexcept {
    if (this == &other) return *this;
    delete[] coefficients_;
    degree_ = other.degree_;
    coefficients_ = other.coefficients_;
    other.degree_ = -1;
    other.coefficients_ = nullptr;
    return *this;
}

template <typename T> 
T& Polynomial<T>::operator[](size_t i) {
    return coefficients_[degree_ - i];
}
template <typename T>
const T& Polynomial<T>::operator[](size_t i) const {
    return coefficients_[degree_ - i];
}

template <typename T> 
Polynomial<T>& Polynomial<T>::operator+=(const Polynomial<T>& other) {
    int newDegree = std::max(this->degree_, other.degree_);
    while (newDegree > -1 && this->coefficient(newDegree) + other.coefficient(newDegree) == 0) {
        --newDegree;
    }
    T* newCoefficients = new T[newDegree + 1];
    for (int i = 0; i <= newDegree; ++i) {
        newCoefficients[newDegree - i] = this->coefficient(i) + other.coefficient(i);
    }
    delete[] coefficients_;
    coefficients_ = newCoefficients;
    degree_ = newDegree;
    return *this;
}

template <typename T> 
Polynomial<T>& Polynomial<T>::operator-=(const Polynomial<T>& other) {
    int newDegree = std::max(this->degree_, other.degree_);
    while (newDegree > -1 && this->coefficient(newDegree) - other.coefficient(newDegree) == 0) {
        --newDegree;
    }
    T* newCoefficients = new T[newDegree + 1];
    for (int i = 0; i <= newDegree; ++i) {
        newCoefficients[newDegree - i] = this->coefficient(i) - other.coefficient(i);
    }
    delete[] coefficients_;
    coefficients_ = newCoefficients;
    degree_ = newDegree;
    return *this;
}

template <typename T> 
Polynomial<T>& Polynomial<T>::operator*=(const Polynomial<T>& other) {
    int newDegree = this->degree_ + other.degree_;
    T* newCoefficients = new T[newDegree + 1];
    for (int i = 0; i <= newDegree; ++i) {
        newCoefficients[newDegree - i] = 0; // coefficient of x^i
        for (int k = 0; k <= i; ++k) {
            newCoefficients[newDegree - i] += this->coefficient(k) * other.coefficient(i - k);
        }
    }
    delete[] coefficients_;
    coefficients_ = newCoefficients;
    degree_ = newDegree;
    return *this;
}

template <typename T> 
T Polynomial<T>::operator()(T n) const {
    return eval(n);
}

template <typename T> 
T Polynomial<T>::eval(T n) const {
    auto f = [n](T acc, T val) { return acc * n + val; };
    return std::accumulate(coefficients_, coefficients_ + degree_ + 1, T(0), f);
}

template <typename T> 
T Polynomial<T>::coefficient(int i) const {
    return (i < 0 || i > degree_) ? 0 : coefficients_[degree_ - i];
}

If you want to test that it works, you can run the following code: 

#include <iostream>
#include "polynomial.h"

int main() {
    Polynomial<double> f({1.5, 3.7, 2.8});
    Polynomial<double> g({2, 10});
    std::cout << f + g << std::endl;  // 1.5x^2 + 5.7x + 12.8
    std::cout << f - g << std::endl;  // 1.5x^2 + 1.7x - 7.2
    std::cout << f * g << std::endl;  // 3x^3 + 22.4x^2 + 42.6x + 28
    std::cout << 10 * f << std::endl; // 15x^2 + 37x + 28
    std::cout << f[1] << std::endl;   // 3.7
    std::cout << f(100) << std::endl; // 15372.8
    return 0;
}

On a surface level, transforming Polynomial into a template class wasn't too complicated: we just had to turn every int into T. (Well, not quite all -- we had to be careful not to do that to a non-coefficient int, such as an index.) But there are several things worth noting:

  • When we use the scope resolution operator :: to provide definitions outside the class declaration, we now need to write Polynomial<T> on the left instead of simply Polynomial. (We also need to preface each definition with "template <typename T>" -- the compiler still needs to be told that this is a template.)
  • On the other hand, when we're inside the class declaration we can still simply write Polynomial and the compiler understands that this is Polynomial<T>.
  • The definitions of the friend functions are moved inside the class declaration. This is the easiest way to make friend functions that have the correct template behavior.
  • Updating the eval() method required some care, because we needed to change the accumulator's starting value of 0 to T(0). When it was left as 0, the compiler was interpreting that as an int, and when I tried to use eval() with a Polynomial<double>, it would round all the coefficients down to integers, giving the wrong answer.

Other parameters

You can also parametrize with things other than typenames. For example, you could use an int as a parameter, as we saw with std::array<int, 3>. If you were creating your own Array class, you could parametrize it as: 

template <typename T, int N>
class Array {
    // Your code here
}
