Pointer Arithmetic Exercise (Back to lecture)

Figure out what the below code prints without running it. (You won't be able to predict the last line exactly, but what can you predict about it?) 

#include <iostream>

int main() {
    int nums[9] = {1, 2, 3, 5, 8, 13, 21, 34, 55};
    int* ptr = nums + 5;
    std::cout << *(nums + 2) << std::endl;
    std::cout << ptr[2] << std::endl;
    *ptr = -1;
    ptr -= 4;
    for (; ptr < nums + 6; ++ptr) {
        std::cout << *ptr << std::endl;
    }
    std::cout << nums << ' ' << ptr << std::endl;
    return 0;
}

2D array exercises (Back to lecture)

  1. Define a function makeIdentity which accepts as argument a positive int n and returns (using a C-style array) an n x n identity matrix, i.e., an n x n square grid arr where arr[i][j] is 1 if i == j and 0 otherwise.

    Answer: 

    int** makeIdentity(int n) {
    int** id = new int*[n];
    for (int i = 0; i < n; ++i) {
        id[i] = new int[n];
        for (int j = 0; j < n; ++j) {
            id[i][j] = (i == j) ? 1 : 0;
        }
    }
    return id;
}

    Answer: The below answer uses allocateMatrix, which was provided in my sample code above. But make sure that you understand how it works, and that you could allocate the memory yourself, if you were asked to. 

    double** matrixMultiply(double** a, double** b, int m, int n, int p) {
    double** ab = allocateMatrix(m, p);
    for (int i = 0; i < m; ++i) {
        for (int j = 0; j < p; ++j) {
            ab[i][j] = 0.0;
            for (int k = 0; k < n; ++k) 
                ab[i][j] += a[i][k] * b[k][j];
        }
    }
    return ab;
}

C-style string exercise (Back to lecture)

Define the string copy function void strcpy(char* dest, char* src) which copies the C-style string src into the memory used by the array dest. You may assume that dest has enough memory to hold src.

Answer: Two solutions are provided below: 

void strcpy(char* dest, char* src) {
    int i = 0;
    for (; src[i] != '\0'; ++i)
        dest[i] = src[i];
    dest[i] = '\0';
}
 

void strcpy(char* dest, char* src) {
    while (*src != '\0')
        *(dest++) = *(src++);
    *dest = '\0';
}
