Lecture 03: Control Flow

Control Flow

"Control flow" refers to the order in which statements are executed inside your program. It can be affected by things like conditionals and loops. Fortunately, most of these things are very similar in C++ and Python, so most of what we're about to talk about will seem familiar to you.

if

As in Python, conditionals in C++ are introduced by if. As we've seen, C++ uses braces rather than colon/indentation to determine blocks of code, so you'll indicate the block of code to be executed if the condition is true using braces. (Technically, it's not necessary to use braces if there's only one statement to be executed, but "always use braces" is a popular style anyway.) The other difference is that C++ requires the condition to be written inside parentheses.

Here's a very simple example: 

#include <iostream>
int main() {
    double rating;
    std::cout << "Enter the Rotten Tomatoes score: ";
    std::cin >> rating;
    if (rating >= 60) {
        std::cout << "Fresh!" << std::endl;
    }
    return 0;
}

else

Of course, we sometimes want our program to do one thing when a condition is true, and another when a condition is false. We can put an else block after an if to indicate this: 

#include <iostream>
int main() {
    double rating;
    std::cout << "Enter the Rotten Tomatoes score: ";
    std::cin >> rating;
    if (rating >= 60) {
        std::cout << "Fresh!" << std::endl;
    } else {
        std::cout << "Rotten!" << std::endl;
    }
    return 0;
}

else if

C++'s else if is the equivalent of Python's elif. You can use it when your code has more than two branches and you only want to select one. Naturally, you can still put an else at the end. 

#include <iostream>
int main() {
    double average;
    std::cout << "Enter your course average: ";
    std::cin >> average;
    if (average < 60) {
        std::cout << "F" << std::endl;
    } else if (average < 70) {
        std::cout << "D" << std::endl;
    } else if (average < 80) {
        std::cout << "C" << std::endl;
    } else if (average < 90) {
        std::cout << "B" << std::endl;
    } else {
        std::cout << "A" << std::endl;
    }
    return 0;
}

switch

Sometimes we want our code to branch based on the value of a specific variable, e.g., if x=0 we go down one branch, if x=1 we go down another branch, and so on. We could handle this with a long else if chain, but C++ gives us another option: the switch statement: 

#include <iostream>
int main() {
    int players;
    std::cout << "Enter number of players: ";
    std::cin >> players;
    switch (players) {
        case 0:
            std::cout << "Two computer players will play against each other." << std::endl;
            break;
        case 1:
            std::cout << "You will play against the computer." << std::endl;
            break;
        case 2:
            std::cout << "You will play against another person." << std::endl;
            break;
        default:
            std::cout << "Invalid input." << std::endl;
            break;
    }
    return 0;
}

Some things to be careful with:

  • The value that you switch on must be an integral type (int, char, long, etc.), or something that the compiler can automatically convert to an integral type. You cannot switch on strings or doubles.
  • The value after case must be a constant expression that the compiler can evaluate at compile time; it cannot depend on a variable.
  • By default, after we find the matching case, we execute not just the statements within that case, but also all the following cases. (This is referred to as falling through.) This may sometimes be desirable, if you want several cases to execute the same code, but usually it isn't. Put a break at the end of each case to tell the program to break out of the switch statement and not run the other cases' code.
  • You can include a default block at the end, with code to be run if the input doesn't match any of the cases. This is optional, but generally good practice.

for loops

As in Python, you can use a for loop to iterate. The most basic for loop is when you want to iterate over a specific range, similar to Python's for i in range(5):. You can set up a for loop in C++ by writing for, followed by three statements separated by semicolons (see below), and then the code that you want to iterate inside braces. The three statements that you write are:

  • Initialization: Initialize the counter
  • Condition: The condition to continue looping
  • Update: How to advance to the next iteration, after running the code inside the loop

The most common case looks like this: 

#include <iostream>
int main() {
    for (int i = 0; i < 5; ++i) {
        std::cout << i << " ";
    }
    std::cout << std::endl;
    return 0;
}

This code says that i should be initialized to zero, then after each iteration i should be incremented, continuing while i < 5. Therefore we will get iterations for i=0,1,2,3,4, so this code prints "0 1 2 3 4".

There's no rule that says that the loop variable needs to be incremented by 1 every time. For example, we could write code that prints all the powers of 2 less than 1000, by doubling i every iteration: 

#include <iostream>
int main() {
    for (int i = 1; i < 1000; i *= 2) {
        std::cout << i << " ";
    }
    std::cout << std::endl;
    return 0;
}

There's also no rule that says all three statements inside the parentheses are necessary. For example, if we want to use a variable that's already been initialized, we can skip initialization: 

#include <iostream>
int main() {
    int i;
    std::cout << "Enter a positive integer: ";
    std::cin >> i;
    for (; i >= 0; --i) {
        std::cout << i << " ";
    }
    std::cout << std::endl;
    return 0;
}

The other two are less commonly skipped, but they can be skipped if you don't need them. (Though if you do find yourself skipping them, your code might be easier to read with a while loop instead.) You can even skip all three to create an infinite loop. (Again, while (true) might be considered a clearer way to create at infinite loop, but some old code uses for (;;) to create an infinite loop because this was preferable with old compilers). For example: 

#include <iostream>
int main() {
    for (;;) {
        std::string s;
        std::cout << "What's the magic word? ";
        std::cin >> s;
        if (s == "please") {
            break;
        }
        std::cout << "Wrong!" << std::endl;
    }
    return 0;
}
