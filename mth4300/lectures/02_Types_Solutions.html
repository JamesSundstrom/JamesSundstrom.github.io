Distance Exercise (Back to lecture)

Write a program which asks the user to enter the x- and y-coordinates of two points, and prints the distance between the points.

Hints:

  • You can import std::sqrt from the cmath library.
  • You can use double (which we'll discuss below) as the type for a variable that represents a real number.

Answer: 

#include <iostream>
#include <cmath>

int main() {
    double x0, y0, x1, y1;
    std::cout << "Enter the x- and y-coordinates of the first point, separated by a space: ";
    std::cin >> x0 >> y0;
    std::cout << "Enter the x- and y-coordinates of the second point, separated by a space: ";
    std::cin >> x1 >> y1;
    double dx{x1 - x0}, dy{y1 - y0};
    double dist{std::sqrt(dx*dx + dy*dy)};
    std::cout << "The distance between the points is " << dist << std::endl;
    return 0;
}

Char Exercise (Back to lecture)

What range of values can be stored in a signed char? An unsigned char?

Solution: Since a char is one byte (8 bits), a signed char has 7 non-sign bits, so the maximum value is 27 - 1 = 127 and the minimum value is -27 = -128. Thus the range is [-128, 127].

Similarly, an unsigned char has a maximum value 28 - 1 = 255 and the minimum value is, of course 0. Thus the range is [0, 255].
