Lecture 07: Algorithms

The C++ standard library contains many useful algorithms to sort data, search data, etc. These algorithms are designed to work whether your data is stored in a C-style array, std::array, std::vector, or something else. In order to understand how these algorithms work with various types of containers, we'll first need to understand the concept of an iterator in C++.

Iterators

An iterator is an object that in many ways acts like a pointer. It points into a container, and supports the same operations as a pointer: dereference (*), increment (++), and comparison (==, !=). Depending on the type of the container, some iterators also support inequality comparisons (< and >), decrement (--), and addition/subtraction. Since vectors and arrays support random access (i.e., you can access any element using arr[n] without first accessing all the previous elements), they give you all these operations. A container that doesn't support random access will not give you all these (e.g., if you can only move forward through the container, subtraction won't be supported).

Every standard container provides methods to return iterators begin() and end(). As the name suggests, begin() points to the beginning of the container. However, end() points one past the end of the container, in much the same way that, if arr has length n, then arr[n] points to the memory immediately after the end of arr

If your container has type T, then the iterator has type T::iterator. For example, for a std::vector<double>, the iterator has type std::vector<double>::iterator, which is a bit verbose. You should almost always use auto when declaring an iterator.

As a simple example with iterators, we can use iterators to loop through a vector. Note that the syntax is very similar to looping through an array using a pointer: 

#include <iostream>
#include <vector>

int main() {
    std::vector v = {1.618, 2.718, 3.142};

    for (auto it = v.begin(); it != v.end(); ++it) {
        std::cout << *it << ' '; // Prints 1.618 2.718 3.142
    }
    std::cout << '\n';

    return 0;
}

The above code does the exact same thing as a range-based for loop. Obviously, the range-based for loop is easier, so you wouldn't use the above syntax unless you actually needed the iterator for some reason.

Lambdas

Another concept that will be helpful when we start talking about algorithms is lambdas.

A lambda is an anonymous function; if you have a function that you only need to use once, it may not be worth the trouble to name it and define it as a standalone function in your code. You can instead use a lambda so that the function exists only at the moment that you need it. You may have already seen the concept in Python. For example, you might use a lambda to tell a sorting function the criterion to sort by: 

scores = [("Alice", 92), ("Bob", 83), ("Charlie", 90)]
scores.sort(key=lambda x : x[1], reverse=True)
print(scores)

The lambda function lambda x : x[1] defines a function f(x) = x[1], which tells Python to sort the x's based on their x[1] values. This is a classic use for a lambda: we don't need the function f(x) = x[1] permanently, we just need it temporarily to tell the sort function the sorting criterion. This is also the main way that we'll use lambdas in C++.

C++ lets us do the same thing, with a different-looking syntax. The basic syntax is [capture](parameters) { body }. We'll discuss "capture" in a moment. We use "parameters" to enter the parameters for the function, in exactly the same way that we usually do, and then the body of the function is exactly what it would usually be. For example, we can use a lambda to define a cube function: 

#include <iostream>

int main() {
    auto f = [](int x) { return x*x*x; };
    std::cout << f(5) << std::endl; // Prints 125
    return 0;
}
