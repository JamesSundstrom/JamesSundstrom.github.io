Define a class HighScoreList that will keep track of the top n scores in a game. Scores will be ints, and only positive scores are allowed to be posted on the high score list. The list will track only the scores themselves; you don't need to attach names to the scores. Your class should include the following:

  • A constructor that takes one argument, an int size, and creates an empty high score list with a maximum size of size. (I.e., one there are size scores stored, any new high score must push out an existing high score.)
  • A method addScore, that takes one argument (an int score), and updates the high score list appropriately. (This may mean doing nothing, if the list is already full and the new score is lower than the lowest existing score.)
  • Overload the subscript operator so that if scores is a HighScoreList, then scores[i] returns the high score at index i. (That is, scores[0] is the highest score, scores[1] is the second-highest, and so on.) Your method does not need to check bounds. Unlike the usual subscript operator, this one should not return a reference because we do not want it to be used to modify the high score list directly. The only way to modify the list should be through the addScore method.
  • Overload the <<operator to print all the high scores in a numbered list, one on each line. (See below for an example.)

You should separate your code appropriately into files high_score_list.h and high_score_list.cpp.

For example, the below code should print 

1. 50
2. 45
3. 25

25

#include <iostream> 
#include "high_score_list.h"

int main() {
    HighScoreList scores(3);
    scores.addScore(50);
    scores.addScore(25);
    scores.addScore(5);
    scores.addScore(45);
    scores.addScore(20);
    std::cout << scores << std::endl;    // 1. 50   2. 45   3. 25
    std::cout << scores[2] << std::endl; // 25
    return 0;
}

Solution: The solution is provided below. Note that in this solution, the high score is pre-populated with dummy scores of 0 when it is constructed. This automatically enforces that only positive scores can be added to the list, and avoids the need to write separate code for the cases where the list is or is not full. 

// high_score_list.h

#include <ostream> 
#include <vector>

class HighScoreList {
private:
    int size_;
    std::vector<int> scores_;
public:
    HighScoreList(int size);
    bool addScore(int score);
    int operator[](int i) const;
    friend std::ostream& operator<<(std::ostream& os, HighScoreList scores);
};

// high_score_list.cpp

#include "high_score_list.h"

HighScoreList::HighScoreList(int size) : size_(size), scores_(size_, 0) {}

bool HighScoreList::addScore(int score) {
        int i;
        for (i = 0; i < size_; ++i) {
            if (scores_[i] < score) break;
        }
        if (i == size_) return false;
        for (int j = size_ - 2; j >= i; --j) {
            scores_[j+1] = scores_[j];
        }
        scores_[i] = score;
        return true;
    }

int HighScoreList::operator[](int i) const {return scores_[i];}

std::ostream& operator<<(std::ostream& os, HighScoreList scores) {
    for (int i = 0; i < scores.size_; ++i) {
        if (scores[i] > 0) {
            os << i+1 << ". " << scores[i] << std::endl;
        } else break;
    }
    return os;
}

private:

    double* coords_;
public:
    Point(int d) : dimension_(d), coords_(new double[d]{}) {}
    double& operator[](int i) {return coords_[i];}
    
    // Solution:
    
    // Destructor
    ~Point() {delete[] coords_;}
    
    // Copy constructor
    Point(const Point& other) : 
        dimension_(other.dimension_), 
        coords_(new double[dimension_]) {
        std::copy(other.coords_, other.coords_ + dimension_, coords_);
    }
    
    // Copy assignment
    Point& operator=(const Point& other) {
        if (this == &other) {return *this;}
        delete[] coords_;
        dimension_ = other.dimension_;
        coords_ = new double[dimension_];
        std::copy(other.coords_, other.coords_ + dimension_, coords_);
        return *this;
    }
    
    // Move constructor
    Point(Point&& other) noexcept : 
        dimension_(other.dimension_), 
        coords_(other.coords_) {
        other.dimension_ = 0; 
        other.coords_ = nullptr;
    }
    
    // Move assignment

        if (this == &other) return *this;
        delete[] coords_;
        dimension_ = other.dimension_;
        coords_ = other.coords_;
        other.dimension_ = 0;
        other.coords_ = nullptr;

    }

(a) There is a bug that will cause this code to fail to compile. How would you fix it? (Hint: It's related to the speak() method for Parrot.)

Solution: The problem is that the speak() method for Parrot uses the name_ attribute from Animal, but that attribute was declared as private, so it's not accessible to derived classes. The fix is to change Animal so that name_ is declared as protected_. (Note: for full credit, you must make it protected, not public. A bug fix should always change as little as possible from the original code, and making an attribute public is a significant change that should not be made without good reason.)

(b) The above code is supposed to print Woof! followed by I'm Polly!. But that's not what it actually prints. State what it actually prints, and explain how to fix the bug so that it prints what it should.

Solution: As written, this code prints Animal noises twice. The problem is that the speak() method for Animal was not declared as virtual. When we call speak() via a pointer to Animal, it uses Animal's speak() rather than the method for the derived class. (On the other hand, if we called polly.speak() directly, it would print I'm Polly! -- make sure you understand why.)

Define a class Auction. Each Auction should have attributes:

  • highest_bidder, a string representing the current highest bidder;
  • highest_bid, an int> representing the current highest bid;
  • open, a bool which is true if the auction is currently accepting further bids, and false if not.

The class should have a constructor that takes no arguments, sets the highest_bidder attribute to an empty string, the highest_bid attribute to 0, and the open attribute to true. The class should also have the following methods:

  • A method bid() that takes two arguments representing a new bid, a string name with the name of the bidder and an int bid with the value of the bid. If bid is greater than the current highest bid and the auction is open, then the attributes should be updated appropriately; otherwise, do nothing.
  • A method close() that takes no arguments and sets to open attribute to false.

Next, define a class BuyNowAuction that inherits from Auction and allows a bidder to buy the item immediately by paying a sufficiently high price. The constructor should accept an additional argument price and set a corresponding attribute buy_now_price. The bid method should work exactly the same as above, except that it should also close the auction if bid is greater than or equal to buy_now_price. For full credit, you must take full advantage of inheritance to minimize the amount of repeated code.

Solution: The solution is below. Note the use of Auction::bid within the definition of BuyNowAuction::bid. I didn't mention in class that this is an option, so I wouldn't penalize you if you rewrote the code from Auction::bid here instead of calling Auction::bid, but it's a nice trick to know. (Also note that if you were to rewrite the code here, you would need to make all attributes of Auction protected rather than private.) 

#include <string>

class Auction {
private:
    bool open{true};
    std::string highest_bidder{""};
protected:
    int highest_bid{0};
public:
    virtual void bid(const std::string& name, int bid) {
        if (bid <= highest_bid || !open) return;
        highest_bid = bid;
        highest_bidder = name;
    }
    void close() {open = false;}
};

class BuyNowAuction : public Auction {
private:
    int buy_now_price;
public:
    BuyNowAuction(int price) : Auction(), buy_now_price(price) {}
    void bid(const std::string& name, int bid) {
        Auction::bid(name, bid);
        if (highest_bid >= buy_now_price) close();
    }
};

Define a function template secondHighest that accepts as argument a const reference to a std::vector (of any type that implements the < operator), and returns the value of the second-highest entry in the vector. (If the highest value appears twice, then it also counts as the second-highest value.)

Solution: 

template <typename T>
T secondHighest(const std::vector<T>& v) {
    T hi, hi2;
    if (v[0] < v[1]) {hi = v[1]; hi2 = v[0];}
    else {hi = v[0]; hi2 = v[1];}
    for (int i = 2; i < v.size(); ++i) {
        T val = v[i];
        if (val > hi) {
            hi2 = hi;
            hi = val;
        } else if (val > hi2) {
            hi2 = val;
        }
    }
    return hi2;
}

Define a class Vector that represents a 2-dimensional vector (in the sense of linear algebra). That is, each Vector contains an x-coordinate and a y-coordinate (as doubles). Vectors can be added componentwise (i.e., (2, 3) + (-1, 4) = (1, 7)) and can be multiplied componentwise by numbers (i.e., 5 * (2, 3) = (10, 15)). Note that this multiplication is always written with the number on the left, so (2, 3) * 5 does not need to be defined.

The constructor should take two doubles as arguments, representing the x- and y-coordinates, and construct a Vector accordingly.

Overload the operators +, *, +=, and *= as described above, so that two vectors can be added or a vector can be multiplied by a number (on the left). Also overload the << operator to print the vector, in the format "(x, y)".

For example, the below code should print (11, 16) (5, 7) (27, 39). 

#include <iostream>
int main() {
    Vector v(2, 3);
    Vector w(5, 7);
    v *= 3; // v = (6, 9)
    v += w; // v = (11, 16)
    Vector u = 2 * v + w; // u = (28, 41)
    std::cout << v << ' ' << w << ' ' << u << std::endl;
    return 0;
}

Solution:

#include <ostream>

class Vector {
private:
    double x_;
    double y_;
public: 
    Vector(double x, double y) : x_{x}, y_{y} {};
    Vector& operator+=(const Vector& other) {
        x_ += other.x_;
        y_ += other.y_;
        return *this;
    }
    friend Vector operator+(Vector v, const Vector& w) {
        v += w;
        return v;
    }
    Vector& operator*=(double c) {
        x_ *= c;
        y_ *= c;
        return *this;
    }
    friend Vector operator*(double c, Vector v) {
        v *= c;
        return v;
    }
    friend std::ostream& operator<<(std::ostream& os, const Vector& v) {
        os << '(' << v.x_ << ", " << v.y_ << ')';
        return os;
    }
};
