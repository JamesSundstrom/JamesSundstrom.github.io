Define a class HighScoreList that will keep track of the top n scores in a game. Scores will be ints, and only positive scores are allowed to be posted on the high score list. The list will track only the scores themselves; you don't need to attach names to the scores. Your class should include the following:

  • A constructor that takes one argument, an int size, and creates an empty high score list with a maximum size of size. (I.e., one there are size scores stored, any new high score must push out an existing high score.)
  • A method addScore, that takes one argument (an int score), and updates the high score list appropriately. (This may mean doing nothing, if the list is already full and the new score is lower than the lowest existing score.)
  • Overload the subscript operator so that if scores is a HighScoreList, then scores[i] returns the high score at index i. (That is, scores[0] is the highest score, scores[1] is the second-highest, and so on.) Your method does not need to check bounds. Unlike the usual subscript operator, this one should not return a reference because we do not want it to be used to modify the high score list directly. The only way to modify the list should be through the addScore method.
  • Overload the <<operator to print all the high scores in a numbered list, one on each line. (See below for an example.)

You should separate your code appropriately into files high_score_list.h and high_score_list.cpp.

For example, the below code should print 

1. 50
2. 45
3. 25

25

#include <iostream> 
#include "high_score_list.h"

int main() {
    HighScoreList scores(3);
    scores.addScore(50);
    scores.addScore(25);
    scores.addScore(5);
    scores.addScore(45);
    scores.addScore(20);
    std::cout << scores << std::endl;    // 1. 50   2. 45   3. 25
    std::cout << scores[2] << std::endl; // 25
    return 0;
}

Define a class template Range that works with any type T that can be compared using <=. The class should define a range by allowing the user to provide values of type T, and keeping track of the minimum and maximum. After that, the Range object represents the range [min, max], i.e., it consists of all values that lie between the minimum and maximum provided values (inclusive).

The class should have a method expand that takes an argument of type T and updates the min/max values, if necessary. It should also have a method contains that takes an argument of type T and returns a bool reflecting whether the provided value is in the range.

For example, the below code should print 010. The range rng is ["bat", "dog"], which does not contain "alligator" but does contain "bear". The range empty is empty, so it does not contain anything. 

#include <iostream>
#include <string>
int main() {
    Range<std::string> rng;
    rng.expand("cat");
    rng.expand("dog");
    rng.expand("bat");
    std::cout << rng.contains("alligator") << rng.contains("bear");
    Range<double> empty;
    std::cout << empty.contains(0.0) << std::endl;
}

Define a class Vector that represents a 2-dimensional vector (in the sense of linear algebra). That is, each Vector contains an x-coordinate and a y-coordinate (as doubles). Vectors can be added componentwise (i.e., (2, 3) + (-1, 4) = (1, 7)) and can be multiplied componentwise by numbers (i.e., 5 * (2, 3) = (10, 15)). Note that this multiplication is always written with the number on the left, so (2, 3) * 5 does not need to be defined.

The constructor should take two doubles as arguments, representing the x- and y-coordinates, and construct a Vector accordingly.

Overload the operators +, *, +=, and *= as described above, so that two vectors can be added or a vector can be multiplied by a number (on the left). Also overload the << operator to print the vector, in the format "(x, y)".

For example, the below code should print (11, 16) (5, 7) (27, 39). 

#include <iostream>
int main() {
    Vector v(2, 3);
    Vector w(5, 7);
    v *= 3; // v = (6, 9)
    v += w; // v = (11, 16)
    Vector u = 2 * v + w; // u = (28, 41)
    std::cout << v << ' ' << w << ' ' << u << std::endl;
    return 0;
}
